## 2. 確定した仕様

1. 式(40)の1階負荷は、補正前の熱源機出力を空調対象面積比で按分する。
2. 式(40)の床下温度収支面積は、1階空調対象室（ゾーン1・2）の46.37 m²とする。
3. 式(40)で元の負荷から除く床損失には一般床断熱の熱貫流率を、床下から室への供給には無断熱床の熱貫流率を使用する。
4. 冷房の式(40)には冷房顕熱出力のみを使用する。
5. 冷房時を含む地盤応答は、付録Eの時刻別応答を使用する。
6. 式(52)と式(48)の非居室床下貫流面積は、浴室を含む1階床下接触面積19.04 m²とする。外皮・換気項には非居室全体38.93 m²を使用する。
7. 式(9)は、居室から非居室への熱移動を正とする $`Q^*_{trs,prt,i}`$ の定義を維持し、冷房負荷ではこれを差し引く。床損失補正符号と式(46)の直接床項はExcelの計算方法を優先する。

## ① 式(40)：熱源機出力の床下補正

### ①-1 空調対象面積による1階負荷の按分

空調対象室はゾーン1～5であり、床下から空気を供給する1階空調対象室はゾーン1・2である。

```math
A_{s,uf,HCZ,1F}
=
\sum_{i=1}^{5} r_{A,uf,i} A_{HCZ,i}
=46.37\ \mathrm{m^2}
```

```math
A_{HCZ,A}
=
\sum_{i=1}^{5} A_{HCZ,i}
=81.15\ \mathrm{m^2}
```

```math
r_{1F}
=
\frac{A_{s,uf,HCZ,1F}}{A_{HCZ,A}}
=
\frac{46.37}{81.15}
=0.5714109673
```

暖房時の1階負荷は次式とする。

```math
L_{H,1F,d,t}
=
\hat{Q}_{hs,H,d,t}\,r_{1F}
```

冷房時は冷房顕熱出力だけを按分する。

```math
L_{CS,1F,d,t}
=
\hat{Q}_{hs,CS,d,t}\,r_{1F}
```

コード内部では冷房負荷を負値として床下温度式へ渡す。

### ①-2 床下温度式

熱貫流率は用途ごとに分ける。

| 記号 | 値（今回の住戸） | 用途 |
|---|---:|---|
| $`U_{s,load}`$ | 0.542226 W/(m²K) | 元の暖冷房負荷に含まれる一般床断熱の損失 |
| $`U_{s,supply}`$ | 2.223 W/(m²K) | 無断熱床を通した床下から室への熱供給 |

暖房時は次式とする。

```math
\theta_{uf,d,t}
=
\theta_{in,d,t}
+
\frac{
L_{H,1F,d,t}10^3
-
U_{s,load}A_{s,uf,HCZ,1F}H_{floor}
(\theta_{in,d,t}-\theta_{ex,d,t})3.6
}{
\rho_{air}c_{air}V_{1F,d,t}
+
U_{s,supply}A_{s,uf,HCZ,1F}3.6
}
```

冷房時は、$`L_{CS,1F,d,t}`$ を正の負荷量として次式とする。

```math
\theta_{uf,d,t}
=
\theta_{in,d,t}
-
\frac{
L_{CS,1F,d,t}10^3
-
U_{s,load}A_{s,uf,HCZ,1F}H_{floor}
(\theta_{ex,d,t}-\theta_{in,d,t})3.6
}{
\rho_{air}c_{air}V_{1F,d,t}
+
U_{s,supply}A_{s,uf,HCZ,1F}3.6
}
```

ここで $`H_{floor}=0.7`$、$`\rho_{air}=1.2\ \mathrm{kg/m^3}`$、$`c_{air}=1.006\ \mathrm{kJ/(kg\,K)}`$ である。

### ①-3 熱源機出力の補正

```math
\hat{Q}^{uf}_{hs,d,t}
=
\hat{Q}_{hs,d,t}
-
\Delta L_{floor,d,t}
+
\Delta L_{out,d,t}
+
\Delta L_{gnd,d,t}
```

元の負荷に含まれる床損失は次式で除く。

```math
\Delta L_{floor,d,t}
=
\frac{
U_{s,load}A_{s,uf,HCZ,1F}H_{floor}
\left|\theta_{in,d,t}-\theta_{ex,d,t}\right|3.6
}{1000}
```

床下から外気への周辺部熱損失は次式とする。

```math
\Delta L_{out,d,t}
=
\frac{
\phi L_{uf}\Delta\theta_{uf,out,d,t}3.6
}{1000}
```

今回の住戸では $`\phi=0.846\ \mathrm{W/(m\,K)}`$、$`L_{uf}=32.9976\ \mathrm{m}`$ である。床下空間全体の外気・地盤補正には全床下接触面積65.41 m²を使用し、床上への供給面積46.37 m²と区別する。

## ③ 式(8)・式(9)：負荷バランス時のゾーン負荷

暖房時は、通常の負荷に間仕切り熱移動を加え、元の床損失を除く。

```math
L^*_{H,i}
=
\max\left(
L_{H,i}
+
Q^*_{trs,prt,i}
-
\Delta L_{floor,i},
0
\right)
```

$`Q^*_{trs,prt,i}`$ は、居室から非居室への熱移動を正として次式で定義される。

```math
Q^*_{trs,prt,i}
=
U_{prt}A_{prt,i}
\left(
\theta^*_{HBR}
-
\theta^*_{NR}
\right)
```

冷房時は通常、非居室温度が居室設定温度より高いため $`Q^*_{trs,prt,i}<0`$ となる。この負値は非居室から居室への熱取得を表すため、正値で表す冷房負荷から差し引く。床損失分はExcelに合わせて加算する。

```math
L^*_{CS,i}
=
\max\left(
L_{CS,i}
-
Q^*_{trs,prt,i}
+
\Delta L_{floor,i},
0
\right)
```

## ④ 新床下空調：熱源機出口の要求温度

新床下空調では、ゾーン1・2が接続された一つの床下空間の熱収支から要求温度を求める。まず、補正後負荷と補正風量をゾーン1・2について合計する。

```math
\begin{aligned}
L^*_{H,1F}&=L^*_{H,1}+L^*_{H,2},\\
L^*_{CS,1F}&=L^*_{CS,1}+L^*_{CS,2},\\
V'_{1F}&=V'_{supply,1}+V'_{supply,2}.
\end{aligned}
```

次に、室温を暖房20℃、冷房27℃として、1階空調対象室へ必要な熱量を渡せる目標床下温度を計算する。

```math
\theta_{uf,target,H}
=
\theta_{in,H}
+
\frac{L^*_{H,1F}10^3}
{\rho_{air}c_{air}V'_{1F}+U_sA_{s,uf,HCZ,1F}3.6}
```

```math
\theta_{uf,target,C}
=
\theta_{in,C}
-
\frac{L^*_{CS,1F}10^3}
{\rho_{air}c_{air}V'_{1F}+U_sA_{s,uf,HCZ,1F}3.6}
```

ここで、$`U_s=2.223\ \mathrm{W/(m^2\,K)}`$、$`A_{s,uf,HCZ,1F}=46.37\ \mathrm{m^2}`$ とする。

熱源機出口温度 $`\theta_{sa}`$ を与えたときの床下温度は、床下と居室、外気および地盤との全熱収支を用いて次の形で表す。

```math
f(\theta_{sa})
=
\frac{\rho_{air}c_{air}V_{sa,A}\theta_{sa}+B}
{\rho_{air}c_{air}V_{sa,A}+D}
```

```math
\begin{aligned}
B={}&\left[
\sum_{j=1}^{12}U_sA_{s,uf,j}H^*_j\theta^*_j
+\phi L_{uf}\theta_{ex}
+\frac{A_{s,uf,A}/R_g}{1+\Phi_{A,0}/R_g}
\left(\sum_m\theta'_{g,surf,A,m}+\theta_{g,avg}\right)
\right]3.6,\\
D={}&\left[
\sum_{j=1}^{12}U_sA_{s,uf,j}H^*_j
+\phi L_{uf}
+\frac{A_{s,uf,A}/R_g}{1+\Phi_{A,0}/R_g}
\right]3.6.
\end{aligned}
```

$`f(\theta_{sa,inv})=\theta_{uf,target}`$ となる $`\theta_{sa,inv}`$ を数値的に逆算する。最後に、暖房は20℃以上、冷房は27℃以下に制限する。

```math
\theta_{req,1}=\theta_{req,2}=
\begin{cases}
\max(\theta_{sa,inv},20) & \text{暖房時},\\
\min(\theta_{sa,inv},27) & \text{冷房時}.
\end{cases}
```

ゾーン1とゾーン2は同一の床下空間に接続されるため、負荷と風量の寄与はゾーン別であるが、目標床下温度と最終要求温度は共通となる。
