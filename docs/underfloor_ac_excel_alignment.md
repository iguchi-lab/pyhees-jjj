## 2. ①～⑦の確定した仕様

### ① 式(40)：熱源機出力の床下補正

式(40)では、1階負荷を住宅全体面積ではなく空調対象面積で按分する。分子は床下から空気を供給するゾーン1・2の46.37 m²、分母は空調対象であるゾーン1～5の81.15 m²とする。また、元の負荷から除く床損失には一般床断熱の熱貫流率0.542226 W/(m²K)、床下から居室へ供給される熱には無断熱床の2.223 W/(m²K)を使い分ける。暖房時は床・外気・地盤の全補正を合計した後、補正後熱源機出力を0以上に制限する。冷房時の床下補正は顕熱だけに適用し、潜熱は0下限処理後に1回だけ加える。基礎の線熱貫流率は3章 付録E 式(5)、地盤の不易層温度は3章 付録E 式(10)から算定する。地盤応答を更新する地盤吸熱量には、目標床下温度ではなく、熱源機出力上限等を反映した1時間前の実際の床下温度を使う。暖房・中間期・冷房を独立した履歴にはせず、同じ一本の年間実床下温度履歴として地盤応答へ渡す。

### ② 式(52)：負荷バランス時の非居室温度

式(52)では、外皮・換気による非居室の熱収支には非居室全体38.93 m²を使う一方、床下から非居室への貫流には1階で床下に接する19.04 m²だけを使う。冷房時の空調風量は顕熱だけではなく、式(40)で確定した顕熱・潜熱の合計出力から求める。

### ③ 式(8)・式(9)：負荷バランス時のゾーン負荷

式(8)・式(9)では、$`Q^*_{trs,prt,i}`$ を「居室から非居室へ移動する熱を正」と定義する。したがって暖房負荷では加算し、冷房負荷では減算する。床損失補正は暖房負荷から差し引き、冷房負荷へ加算し、ゾーン1・2とも最終値を0以上に制限する。

### ④ 熱源機出口の要求温度

熱源機出口の要求温度は、ゾーン1とゾーン2を別々の床下空間として扱わず、両ゾーンの補正後負荷と風量を合計した一つの床下空間の熱収支から求める。目標床下温度の暖房式・冷房式・中間期式の切替えには、外気温度20℃未満・27℃超による再判定ではなく、4章2節で定める地域別の暖房期間・冷房期間・中間期を使用する。地盤応答は現在時刻の応答セルを参照するが、その応答セル自体は1時間前の実際の床下温度から求めた地盤吸熱量で更新されるため、同一時刻の循環参照は生じない。

### ⑤ 式(41)：供給温度

式(41)では、通常のダクト温度降下式を適用せず、床下を通過した後の床下温度をゾーン1・2の供給温度とする。両ゾーンは同じ床下空間に接続されるため供給温度は共通となる。

### ⑥ 式(46)：実際の居室温度

式(46)では、空気による供給熱に加えて、無断熱床を通した直接熱移動 $`2.223 A_{s,uf,i}(\theta_{uf}-\theta^*_{HBR})`$ を分子と分母の双方へ追加する。暖房は設定温度を下限とする `MAX`、冷房は設定温度を上限とする `MIN` を使い、ゾーン1・2の暖房・冷房すべてに同じ考え方を適用する。コードの直接床項を無効化していた `U_s_override=0.0` は廃止した。また、供給空気温度が居室温度を下回るときの熱量を「処理暖房負荷」の負値として扱わず、処理暖房負荷を0以上に制限する。

### ⑦ 式(48)：実際の非居室温度

式(48)では、非居室の床下貫流面積を $`\sum A_{s,uf,NR}+10.76=19.04\ \mathrm{m^2}`$ とする。Excel式は `SUM(E9:E11)+10.76` とし、10.76 m²を合計範囲の各セルへ重複加算しない。式(46)で求めたゾーン1～5の実際の居室温度を使って非居室温度を計算する。

## ① 式(40)：熱源機出力の床下補正

### ①-1 空調対象面積による1階負荷の按分

空調対象室はゾーン1～5であり、床下から空気を供給する1階空調対象室はゾーン1・2である。

```math
A_{s,uf,HCZ,1F}
=
\sum_{i=1}^{5} r_{A,uf,i} A_{HCZ,i}
=46.37\ \mathrm{m^2}
```

```math
A_{HCZ,A}
=
\sum_{i=1}^{5} A_{HCZ,i}
=81.15\ \mathrm{m^2}
```

```math
r_{1F}
=
\frac{A_{s,uf,HCZ,1F}}{A_{HCZ,A}}
=
\frac{46.37}{81.15}
=0.5714109673
```

暖房時の1階負荷は次式とする。

```math
L_{H,1F,d,t}
=
\hat{Q}_{hs,H,d,t}\,r_{1F}
```

冷房時は冷房顕熱出力だけを按分する。

```math
L_{CS,1F,d,t}
=
\hat{Q}_{hs,CS,d,t}\,r_{1F}
```

コード内部では冷房負荷を負値として床下温度式へ渡す。

### ①-2 床下温度式

熱貫流率は用途ごとに分ける。

| 記号 | 値（今回の住戸） | 用途 |
|---|---:|---|
| $`U_{s,load}`$ | 0.542226 W/(m²K) | 3章 付録E 式(4)で算定する、元の暖冷房負荷に含まれる一般床断熱の損失 |
| $`U_{s,supply}`$ | 2.223 W/(m²K) | 無断熱床を通した床下から室への熱供給 |

暖房時は次式とする。

```math
\theta_{uf,d,t}
=
\theta_{in,d,t}
+
\frac{
L_{H,1F,d,t}10^3
-
U_{s,load}A_{s,uf,HCZ,1F}H_{floor}
(\theta_{in,d,t}-\theta_{ex,d,t})3.6
}{
\rho_{air}c_{air}V_{1F,d,t}
+
U_{s,supply}A_{s,uf,HCZ,1F}3.6
}
```

冷房時は、$`L_{CS,1F,d,t}`$ を正の負荷量として次式とする。

```math
\theta_{uf,d,t}
=
\theta_{in,d,t}
-
\frac{
L_{CS,1F,d,t}10^3
-
U_{s,load}A_{s,uf,HCZ,1F}H_{floor}
(\theta_{ex,d,t}-\theta_{in,d,t})3.6
}{
\rho_{air}c_{air}V_{1F,d,t}
+
U_{s,supply}A_{s,uf,HCZ,1F}3.6
}
```

ここで $`H_{floor}=0.7`$、$`\rho_{air}=1.2\ \mathrm{kg/m^3}`$、$`c_{air}=1.006\ \mathrm{kJ/(kg\,K)}`$ である。

### ①-3 熱源機出力の補正

```math
\hat{Q}^{uf}_{hs,H,d,t}
=
\max\left(
\hat{Q}_{hs,d,t}
-
\Delta L_{floor,d,t}
+
\Delta L_{out,d,t}
+
\Delta L_{gnd,d,t},
0
\right)
```

暖房の補正項は要求出力を低減させる場合があるが、補正後の負値は「暖房不要」を意味するため、負の暖房出力として後段へ渡さず0とする。0下限は個々の補正項ではなく、すべての補正を合計した後に適用する。Excelの `負荷計算!CG5:CG8764` における `MAX(床下計算①!P,0)` と同じ扱いである。

元の負荷に含まれる床損失は次式で除く。

```math
\Delta L_{floor,d,t}
=
\frac{
U_{s,load}A_{s,uf,HCZ,1F}H_{floor}
\left|\theta_{in,d,t}-\theta_{ex,d,t}\right|3.6
}{1000}
```

床下から外気への周辺部熱損失は次式とする。

```math
\Delta L_{out,d,t}
=
\frac{
\phi L_{uf}\Delta\theta_{uf,out,d,t}3.6
}{1000}
```

今回の住戸では、3章 付録E 式(5)から $`\phi=0.8459576178\ \mathrm{W/(m\,K)}`$、3章 付録E 式(10)から $`\theta_{g,avg}=15.68613014\ ^\circ\mathrm{C}`$ となる。$`L_{uf}=32.9976\ \mathrm{m}`$ である。床下空間全体の外気・地盤補正には全床下接触面積65.41 m²を使用し、床上への供給面積46.37 m²と区別する。

入力値として保持されていた丸め値（$`\phi=0.846`$、$`\theta_{g,avg}=15.7`$）は式(40)では使用せず、付録Eの各式から計算した値を使用する。床下12の `床下定数!E26` は0.846が直接入力されているため、付録E 式(5)の0.8459576178へ戻す必要がある。`床下定数!E31` は付録E 式(10)に相当する外気温年平均15.68613014℃を計算しており、コードと一致する。

#### 地盤応答の時刻関係

付録Eの応答成分は次式で計算する。

```math
q_{g,t-1}
=
\frac{
\theta_{uf,actual,t-1}-\theta_{g,surf,t-1}
}{R_g}
```

```math
\theta'_{m,t}
=
\phi_{1,m}q_{g,t-1}
+
r_m\theta'_{m,t-1}
```

ここで現在時刻 $`t`$ の応答温度 $`\theta'_{m,t}`$ が参照するのは、1時間前の地盤吸熱量 $`q_{g,t-1}`$ と応答温度 $`\theta'_{m,t-1}`$ である。$`q_{g,t-1}`$ に使う $`\theta_{uf,actual,t-1}`$ は、熱源機の出力上限や実際の出口温度を反映した床下温度であり、式(40)で先に求める目標床下温度ではない。この1時間遅れにより、現在時刻の熱源機計算より先に応答を確定でき、同一時刻の循環参照は生じない。

1月1日1:00について、Excelの `床下温度!AG8774` は1時間前の地盤吸熱量 `床下温度!V8773` だけを使って計算され、値は4.1337647322 ℃である。床下12では暖房側 `床下計算①!O6` が `AG8774` を参照するよう修正され、`O6:O8765` の全8760時間で現在時刻の応答行と一致した。

差し替え後は、冷房側 `床下計算①!S6:S8765` も現在時刻の応答行を参照する。さらに、要求温度計算の `床下計算④!O6:O8765` と供給温度計算の `床下計算⑤!N6:N8765` も同じ時刻関係へ統一された。コードは従来、式(40)で求めた目標床下温度を地盤応答へ渡していたが、修正後は実際の床下温度系列を渡し、$`\theta_{uf,actual,t-1}\rightarrow q_{g,t-1}\rightarrow\theta'_{m,t}`$ の順で更新する。

コードは年間配列のベクトル計算を維持するため、1回目で得た実床下温度を次回の地盤応答へ渡す反復で同じ因果関係を実現する。反復に使用する年間履歴は次のように一本化する。

```math
\theta_{uf,actual,d,t}
=
\begin{cases}
\theta_{uf,H,d,t} & (d,t\in H)\\
\theta_{uf,M,d,t} & (d,t\in M)\\
\theta_{uf,C,d,t} & (d,t\in C)
\end{cases}
```

暖房期は暖房計算の実床下温度、冷房期は冷房計算の実床下温度、中間期は式(21)の熱収支から求めた実床下温度を使う。暖房計算と冷房計算はこの共通履歴から同じ地盤応答を受け取り、暖房用・冷房用に別々の年間履歴を作らない。収束判定は全8,760時間の最大温度差が $`10^{-4}\ \mathrm{K}`$ 以下とし、反復上限は24回とする。この反復はベクトル実装上の解法であり、仕様上の同一時刻の収束計算を意味しない。

## ③ 式(8)・式(9)：負荷バランス時のゾーン負荷

暖房時は、通常の負荷に間仕切り熱移動を加え、元の床損失を除く。

```math
L^*_{H,i}
=
\max\left(
L_{H,i}
+
Q^*_{trs,prt,i}
-
\Delta L_{floor,i},
0
\right)
```

$`Q^*_{trs,prt,i}`$ は、居室から非居室への熱移動を正として次式で定義される。

```math
Q^*_{trs,prt,i}
=
U_{prt}A_{prt,i}
\left(
\theta^*_{HBR}
-
\theta^*_{NR}
\right)
```

冷房時は通常、非居室温度が居室設定温度より高いため $`Q^*_{trs,prt,i}<0`$ となる。この負値は非居室から居室への熱取得を表すため、正値で表す冷房負荷から差し引く。床損失分はExcelに合わせて加算する。

```math
L^*_{CS,i}
=
\max\left(
L_{CS,i}
-
Q^*_{trs,prt,i}
```

## ④ 新床下空調：熱源機出口の要求温度

新床下空調では、ゾーン1・2が接続された一つの床下空間の熱収支から要求温度を求める。まず、補正後負荷と補正風量をゾーン1・2について合計する。

