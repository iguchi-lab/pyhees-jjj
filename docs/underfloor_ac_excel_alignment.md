## 1. 比較条件

## 2. 確定した仕様

1. 式(40)の1階負荷は、補正前の熱源機出力を空調対象面積比で按分する。
2. 式(40)の床下温度収支面積は、1階空調対象室（ゾーン1・2）の46.37 m²とする。
3. 式(40)で元の負荷から除く床損失には一般床断熱の熱貫流率を、床下から室への供給には無断熱床の熱貫流率を使用する。
4. 冷房時の床下温度計算には冷房顕熱出力のみを使用する。一方、式(36)の風量計算に用いる補正後熱源機出力は、式(40-2a)に従い顕熱と潜熱の合計を基礎とし、床下による顕熱補正を加減した値とする。
5. 冷房時を含む地盤応答は、付録Eの時刻別応答を使用する。
6. 式(52)と式(48)の非居室床下貫流面積は、浴室を含む1階床下接触面積19.04 m²とする。外皮・換気項には非居室全体38.93 m²を使用する。
7. 式(9)は、居室から非居室への熱移動を正とする $`Q^*_{trs,prt,i}`$ の定義を維持し、冷房負荷ではこれを差し引く。床損失補正符号と式(46)の直接床項はExcelの計算方法を優先する。

## ① 式(40)：熱源機出力の床下補正

### ①-1 空調対象面積による1階負荷の按分

空調対象室はゾーン1～5であり、床下から空気を供給する1階空調対象室はゾーン1・2である。

```math
A_{s,uf,HCZ,1F}
=
\sum_{i=1}^{5} r_{A,uf,i} A_{HCZ,i}
=46.37\ \mathrm{m^2}
```

```math
A_{HCZ,A}
=
\sum_{i=1}^{5} A_{HCZ,i}
=81.15\ \mathrm{m^2}
```

```math
r_{1F}
=
\frac{A_{s,uf,HCZ,1F}}{A_{HCZ,A}}
=
\frac{46.37}{81.15}
=0.5714109673
```

暖房時の1階負荷は次式とする。

```math
L_{H,1F,d,t}
=
\hat{Q}_{hs,H,d,t}\,r_{1F}
```

冷房時は冷房顕熱出力だけを按分する。

```math
L_{CS,1F,d,t}
=
\hat{Q}_{hs,CS,d,t}\,r_{1F}
```

コード内部では冷房負荷を負値として床下温度式へ渡す。

### ①-2 床下温度式

熱貫流率は用途ごとに分ける。

| 記号 | 値（今回の住戸） | 用途 |
|---|---:|---|
| $`U_{s,load}`$ | 0.542226 W/(m²K) | 元の暖冷房負荷に含まれる一般床断熱の損失 |
| $`U_{s,supply}`$ | 2.223 W/(m²K) | 無断熱床を通した床下から室への熱供給 |

暖房時は次式とする。

```math
\theta_{uf,d,t}
=
\theta_{in,d,t}
+
\frac{
L_{H,1F,d,t}10^3
-
U_{s,load}A_{s,uf,HCZ,1F}H_{floor}
(\theta_{in,d,t}-\theta_{ex,d,t})3.6
}{
\rho_{air}c_{air}V_{1F,d,t}
+
U_{s,supply}A_{s,uf,HCZ,1F}3.6
}
```

冷房時は、$`L_{CS,1F,d,t}`$ を正の負荷量として次式とする。

```math
\theta_{uf,d,t}
=
\theta_{in,d,t}
-
\frac{
L_{CS,1F,d,t}10^3
-
U_{s,load}A_{s,uf,HCZ,1F}H_{floor}
(\theta_{ex,d,t}-\theta_{in,d,t})3.6
}{
\rho_{air}c_{air}V_{1F,d,t}
+
U_{s,supply}A_{s,uf,HCZ,1F}3.6
}
```

ここで $`H_{floor}=0.7`$、$`\rho_{air}=1.2\ \mathrm{kg/m^3}`$、$`c_{air}=1.006\ \mathrm{kJ/(kg\,K)}`$ である。

### ①-3 熱源機出力の補正

```math
\hat{Q}^{uf}_{hs,d,t}
=
\hat{Q}_{hs,d,t}
-
\Delta L_{floor,d,t}
+
\Delta L_{out,d,t}
+
\Delta L_{gnd,d,t}
```

元の負荷に含まれる床損失は次式で除く。

```math
\Delta L_{floor,d,t}
=
\frac{
U_{s,load}A_{s,uf,HCZ,1F}H_{floor}
\left|\theta_{in,d,t}-\theta_{ex,d,t}\right|3.6
}{1000}
```

床下から外気への周辺部熱損失は次式とする。

```math
\Delta L_{out,d,t}
=
\frac{
\phi L_{uf}\Delta\theta_{uf,out,d,t}3.6
}{1000}
```

今回の住戸では $`\phi=0.846\ \mathrm{W/(m\,K)}`$、$`L_{uf}=32.9976\ \mathrm{m}`$ である。床下空間全体の外気・地盤補正には全床下接触面積65.41 m²を使用し、床上への供給面積46.37 m²と区別する。

## ③ 式(8)・式(9)：負荷バランス時のゾーン負荷

暖房時は、通常の負荷に間仕切り熱移動を加え、元の床損失を除く。

```math
L^*_{H,i}
=
\max\left(
L_{H,i}
+
Q^*_{trs,prt,i}
-
\Delta L_{floor,i},
0
\right)
```

$`Q^*_{trs,prt,i}`$ は、居室から非居室への熱移動を正として次式で定義される。

```math
Q^*_{trs,prt,i}
=
U_{prt}A_{prt,i}
\left(
\theta^*_{HBR}
-
\theta^*_{NR}
\right)
```

冷房時は通常、非居室温度が居室設定温度より高いため $`Q^*_{trs,prt,i}<0`$ となる。この負値は非居室から居室への熱取得を表すため、正値で表す冷房負荷から差し引く。床損失分はExcelに合わせて加算する。

```math
L^*_{CS,i}
=
\max\left(
L_{CS,i}
-
Q^*_{trs,prt,i}
+
\Delta L_{floor,i},
0
\right)
```

## ④ 新床下空調：熱源機出口の要求温度

新床下空調では、ゾーン1・2が接続された一つの床下空間の熱収支から要求温度を求める。まず、補正後負荷と補正風量をゾーン1・2について合計する。

```math
\begin{aligned}
L^*_{H,1F}&=L^*_{H,1}+L^*_{H,2},\\
L^*_{CS,1F}&=L^*_{CS,1}+L^*_{CS,2},\\
V'_{1F}&=V'_{supply,1}+V'_{supply,2}.
\end{aligned}
```

ここで $`V'_{supply,i}`$ を決める式(36)の冷房風量には、式(40-2a)の顕熱と潜熱の合計を基礎とした補正後熱源機出力を使用する。床下温度の収支に入る $`L^*_{CS,1F}`$ は、温度差で扱う熱量であるため冷房顕熱負荷のみとする。

次に、室温を暖房20℃、冷房27℃として、1階空調対象室へ必要な熱量を渡せる目標床下温度を計算する。

```math
\theta_{uf,target,H}
=
\theta_{in,H}
+
\frac{L^*_{H,1F}10^3}
{\rho_{air}c_{air}V'_{1F}+U_sA_{s,uf,HCZ,1F}3.6}
```

```math
\theta_{uf,target,C}
=
\theta_{in,C}
-
\frac{L^*_{CS,1F}10^3}
{\rho_{air}c_{air}V'_{1F}+U_sA_{s,uf,HCZ,1F}3.6}
```

ここで、$`U_s=2.223\ \mathrm{W/(m^2\,K)}`$、$`A_{s,uf,HCZ,1F}=46.37\ \mathrm{m^2}`$ とする。

熱源機出口温度 $`\theta_{sa}`$ を与えたときの床下温度は、床下と居室、外気および地盤との全熱収支を用いて次の形で表す。

```math
f(\theta_{sa})
=
\frac{\rho_{air}c_{air}V_{sa,A}\theta_{sa}+B}
{\rho_{air}c_{air}V_{sa,A}+D}
```

```math
\begin{aligned}
B={}&\left[
\sum_{j=1}^{12}U_sA_{s,uf,j}H^*_j\theta^*_j
+\phi L_{uf}\theta_{ex}
+\frac{A_{s,uf,A}/R_g}{1+\Phi_{A,0}/R_g}
\left(\sum_m\theta'_{g,surf,A,m}+\theta_{g,avg}\right)
\right]3.6,\\
D={}&\left[
\sum_{j=1}^{12}U_sA_{s,uf,j}H^*_j
+\phi L_{uf}
+\frac{A_{s,uf,A}/R_g}{1+\Phi_{A,0}/R_g}
\right]3.6.
\end{aligned}
```

$`f(\theta_{sa,inv})=\theta_{uf,target}`$ となる $`\theta_{sa,inv}`$ を数値的に逆算する。最後に、暖房は20℃以上、冷房は27℃以下に制限する。

```math
\theta_{req,1}=\theta_{req,2}=
\begin{cases}
\max(\theta_{sa,inv},20) & \text{暖房時},\\
\min(\theta_{sa,inv},27) & \text{冷房時}.
\end{cases}
```

## ⑤ 式(41)：ゾーン1の供給温度

-

## 4. 床下11で確認したExcel計算式の誤り

### 4-1 冷房潜熱の二重加算

7月22日1:00では、`負荷計算!CC4853=5.1308` が補正前の冷房顕熱＋潜熱、`CA4853=2.6694` が潜熱である。ところが、次の二段階で潜熱が重複する。

1. `床下計算①!T4854` は `CC4853` を基礎として床・外気・地盤補正を行うため、潜熱を含んだ2.2048 MJ/hとなる。
2. `負荷計算!CG4853` は `MAX(T4854,0)+MAX(CA4853,0)` とし、潜熱2.6694 MJ/hをもう一度加えて4.8742 MJ/hとする。

式(40-2a)に合わせる場合は、床下補正を顕熱 `BZ4853` にだけ適用し、0下限処理後に潜熱を1回だけ加える。

```excel
床下計算①!T4854
=MAX(BZ4853+J4854/1000-R4854/1000-S4854/1000,0)
```

```excel
負荷計算!CG4853
=床下計算①!T4854+MAX(CA4853,0)
```

この修正では、`CG4853=2.6694 MJ/h`、`CH4853=270.4125 m³/h`、式(52)の `k_1=410.8515 W/K` となる。床下11の `k_1=441.4316 W/K` は、式(52)自体ではなく入力風量の二重加算が原因である。

### 4-2 式(46)の冷房式が暖房式のままになっている

`床下計算⑥!E4854` と `F4854` は、冷房時にも暖房負荷列 `DL4853`、`DM4853` を参照し、`MAX` でクリップしている。冷房時は冷房負荷列 `DE4853`、`DF4853` を参照し、式(46-2)に従って `MIN` で設定温度を上限とする必要がある。

床から居室への直接床項を除外する今回の比較条件では、ゾーン1は概念的に次式となる。ゾーン2も `FF→FG`、`FM→FN`、`DE→DF` と置き換える。

```excel
=MIN(
  BS4853,
  BS4853-(引用!$C$20*引用!$C$22*FF4853*(BS4853-FM4853)-DE4853*10^6)
  /(引用!$C$20*引用!$C$22*FF4853+(引用!$C$33*仕様!K$13+仕様!$K$4*仕様!K$11)*3600)
)
```

また、現行の `E4854` には直接床項が残る一方、`F4854` では消えており、ゾーン間でも式が不統一である。

### 4-3 式(48)の1階非居室床面積

`床下計算⑦!F4854` と `J4854` は、次の配列式を使用している。

```excel
=床下定数!$E$23*SUM(床下定数!$E$9:$E$11+10.76)*...
```

この式では10.76 m²を3回加算するため、床下面積は40.56 m²となる。正しくは次式の19.04 m²である。

```excel
=床下定数!$E$23*(SUM(床下定数!$E$9:$E$11)+10.76)*...
```

### 4-4 式(9)の0下限処理

`床下計算③!G:H` には式(9)の `MAX(...,0)` がなく、暖房期には負の冷房負荷が表示される。`負荷計算!DE:DF` で後から `MAX` が適用されるため主計算への影響は限定されるが、仕様式とシート単体の値を一致させるには `床下計算③!G:H` 側にも0下限処理を置くべきである。
